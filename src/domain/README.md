# Closeout domain

`closeout.ts` validates one program and classifies reporter-supplied payment evidence, commitments, cash discrepancies and conditional return eligibility. `money.ts` uses exact six-decimal BigInt quantities; no USD conversion. `demo.ts` creates fresh fictional records. The accounting assessment does not fetch chain data, infer purpose, authenticate funder approval or make legal determinations. The separate NEAR reader supplies explicitly marked movement facts; see the root README and `docs/NEAR_RECEIPTS.md`.
